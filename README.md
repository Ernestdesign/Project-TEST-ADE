# CaloTrack - Vanilla Calorie & Nutrition Tracker

A lightweight, responsive calorie and nutrition tracker built with vanilla web technologies.

## Features

- **100% Vanilla Stack**: Pure HTML5, CSS3, and JavaScript. Zero external dependencies, no frameworks, no Tailwind, and no CSS custom properties (variables).
- **Persistent Local Storage**: Saves all food items, diary history, and personalized targets directly in browser `localStorage`. No backend required.
- **Safety Confirmations**: Prompts clear confirmation dialogs before deleting entries, clearing daily records, or resetting data.
- **Daily Dashboard**: Tracks calorie intake against daily targets with an adaptive progress indicator and macronutrient breakdown (Protein, Carbs, Fat).
- **Meal Categorization**: Log meals across Breakfast, Lunch, Dinner, and Snacks with subtotals.
- **Quick Logging**: Fast one-click additions (+50, +100, +200, +500 kcal).
- **Data Portability**: Export and import your diary data via JSON.

## Quick Start

Open `index.html` in any modern web browser. No installation or build steps necessary.
